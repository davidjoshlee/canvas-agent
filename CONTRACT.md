# Implementation contract (MVP)

All paths in context and tasks are vault-relative POSIX paths except WorkspaceContext.vault and ToolkitConfig.vault.path (absolute). Source hashes are SHA256 of original file bytes. Do not copy personal data or configuration from siblings.

Public modules and exact signatures:

- `src/config.ts`: `loadConfig(configPath: string): Promise<ToolkitConfig>`; `createConfig(configPath: string, input: {vault: string; baseUrl: string; tokenEnv?: string; courses?: string[]}): Promise<ToolkitConfig>`. Paths resolved relative to config file. Never replace existing config. Default allowlist empty.
- `src/canvas.ts`: `listCourses(config: ToolkitConfig): Promise<Array<{id: string; code: string; name: string}>>`; `syncCourses(config: ToolkitConfig): Promise<{courses: number; written: string[]; notices: string[]}>`. GET only, env token. Discovery lists readable courses; only sync uses the Canvas ID allowlist. Pagination same-origin; sync never overwrites student edits. Refresh only hash-owned files, preserve untracked files with notices. Save manifest at `_meta/canvas-courses.json` with course mappings and roots; private ownership hashes at `_meta/canvas-sync-state.json`. Handle course-code collision by fail before writing. Remote HTML text normalized locally, originals retained; no model extraction.
- `src/workspace.ts`: `inspectWorkspace(vault: string): Promise<WorkspaceContext>`; `selectCourse(context: WorkspaceContext, query: string): CourseContext`. Recognize course-code and safely manifest-mapped directories; skip private `_meta`, dotfolders, credential-like files and symlinks, preserve relative paths; use frontmatter restrictions/ai_policy/redistribution conservatively. Restricted or prohibited material MUST NOT have text in source records. Unknown binary documents get exclusions. Recognize week/assignment/prep paths, guidance in Resources/Guidance or legacy guidance locations, and relevant root AGENTS.md. Read-only scan. CLI context omits source bodies; task show JSON returns approved snapshots. No database prerequisite for existing School Agent vault. Reject missing/ambiguous course.
- `src/tasks.ts`: `createPrepTask(vault: string, course: string, week: string): Promise<TaskRecord>`; `readTask(vault: string, id: string): Promise<TaskRecord>`. Week is explicit YYYY-MM-DD Monday, validated calendar date. Persist immutable source text snapshot task.json and human TASK.md under `_meta/tasks/<uuid>/`. Select target week materials plus global Resources/Home/syllabus/guidance; don't silently include entire course or prior Prep/drafts. Destination uses existing matching `Week NN - Mon DD/Prep/` or calculated nearest conventional name; ambiguity fails. Existing task sources include safe citation IDs (path). Requirements fixed sections: Summary, Key concepts, Discussion questions, Sources. TASK.md explains candidate identity header `Task: <id>` and citations as exact backtick source paths, missing-source notices, no submissions/no AI-policy authorization.
- `src/completion.ts`: `completeTask(vault: string, id: string, candidateFile: string): Promise<{task: TaskRecord; output: string}>`. Validate task schema, course/destination, identity header, required sections and citations; all original source and guidance byte hashes unchanged; reject candidates that cite paths outside task sources or leak private `_meta`/credential paths. Reject empty candidate, stale/missing sources, symlink paths; version outputs never overwrite existing file (`01 Prep Brief.md`, then `01 Prep Brief.v2.md` etc); atomic save and persisted completion, repeat identical request idempotent. Output stays within authoritative course/week Prep destination, not model-chosen path. Actual correctness/AI permission not guaranteed.
- `src/cli.ts`: Commander entry, `--config` global default `./canvas-agent.config.json`; `init --vault PATH --canvas-url URL [--course ID repeated]`; `courses [--json]`, `sync [--json]`, `context [--json]`, `prep COURSE --week DATE [--json]`, `task show ID [--json]`, `task complete ID --file PATH [--json]`. Human output clear; JSON stable parseable stdout only; errors stderr and exit nonzero, no stack/token exposure. Build dist/cli.js executable shebang.

Each module can depend on shared types but should not run IO on import. Test public exports with Vitest and temp directories; mock Canvas HTTP, no real token/network. Do not implement provider integrations, unattended schedules, assignment generation, or hosted apps in this slice.
